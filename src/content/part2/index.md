# Part 2: 核心篇

核心篇包含 5 章内容，目标是构建 Claude Code 的核心基础设施，让你的 AI 助手具备生产级的架构能力。

## 章节列表

| 章节 | 标题 | 目标 |
|------|------|------|
| Ch6 | 工具系统 | 构建可扩展的工具框架 |
| Ch7 | 权限管理 | 实现多层安全体系 |
| Ch8 | Agent 系统 | 多 Agent 并行与协调 |
| Ch9 | 配置与持久化 | 企业级配置系统 |
| Ch10 | 消息流与 UI | 流畅的用户体验 |

## 学完核心篇你将拥有

- 类型安全的工具系统，支持延迟加载
- 多层权限管理（hooks → rules → dialogs）
- Agent Fork/Resume 模式实现
- 分层配置系统（Enterprise → User）
- 流式消息渲染与进度反馈
